Welcome to the ResLib documentation!

ResLib is a lightweight, production-ready TypeScript library for decorator-based resource management and application utilities.

<!-- truncate -->

## Getting Started

Check out the [Getting Started](/docs/getting-started/installation) guide to begin using ResLib in your projects.

## Features

- 🎯 **Decorator-Driven** - Clean, declarative code
- ✅ **70+ Validation Rules** - Comprehensive validation
- 🌍 **Built-in i18n** - Full internationalization support
- 📦 **Modular** - Tree-shakeable imports
- 🔌 **Cross-Platform** - Web, React Native, Node.js, NestJS

Stay tuned for more updates!
